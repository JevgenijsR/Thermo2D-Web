Геометрия → сетка → проверка → температурное поле.

Как начать свой узел
  1. Откройте «Геометрия JSON / DXF» и загрузите плоский DXF в XY, Z=0.
  2. В «Материалы и теплоотдача» назначьте материал каждой области. Внутреннюю пустоту удалите из списка областей.
  3. Включите «Выбрать грань», щёлкните контур, введите температуру и нажмите «Задать T». Повторите для другой стороны.
  4. Для воздуха измените тип условия на «Воздух + h» в таблице и задайте h. Отметьте внутренние грани для расчёта Tsi,min. Нажмите «Применить параметры».
  5. Рассчитайте и проверьте сходимость на трёх сетках. Скачайте JSON для переноса и резервной копии.

Локальный размер вставки равен минимальному. Для других областей задайте h в таблице. Фактические рёбра и качество показаны после расчёта.

Готов к расчёту. Размеры контрольного узла — тестовые.

Материалы и теплоотдача

λ — Вт/(м·К), ρ — кг/м³, c — Дж/(кг·К). ρ и c справочные, стационарный расчёт использует λ. Начальные значения уточняйте по паспорту.

Добавить свой материал

Температура поверхности — фиксированное T. Воздух — T и h, Вт/(м²·К). Неназначенные грани изолированы. Полости и контактные сопротивления не моделируются.

Геометрия JSON / DXF

LINE и LWPOLYLINE, замкнутые контуры. Кривые, блоки и неподдерживаемые сущности отклоняются. Перед импортом скачайте текущую модель. Вложенный контур сначала становится отдельной областью: для пустоты выберите его и нажмите «Удалить область → отверстие».

Координаты в мм. Области points, holes, lambda, h; грани a, b, temperature, type: film / temperature. Пересечения и наложения отклоняются. Раздельные области требуют температурной опоры.

На другом компьютере загрузите скачанный JSON. Браузерное хранилище не синхронизируется; ваши файлы не отправляются на сервер.

2D — непрерывное включение. Отдельный шуруп требует 3D или обоснованной периодической модели. Эквивалентный крепёж и 3D здесь ещё не реализованы.

Отчёт по границам

Сетка согласована с полигональными контурами и отверстиями. Сгущение геометрическое, с плавным ростом размера; проверка ошибки — последовательное уточнение. Это не сертифицированный расчёт. Малый баланс сам по себе не доказывает пространственную точность.
